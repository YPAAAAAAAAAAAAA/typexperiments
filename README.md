# typexperiments

A clean-room, from-scratch re-implementation of the idea behind **[pablostanley/typexperiments](https://github.com/pablostanley/typexperiments)** by [@pablostanley](https://github.com/pablostanley). The original project had no open-source licence, so no code or assets were copied: only the concept (and its public description) was used as inspiration. All code and assets in this repository are original.
